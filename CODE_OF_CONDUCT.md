# Code of Conduct

ShineEye follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good faith, and never post anyone's personal details (phone numbers, account numbers, names) in issues or pull requests.

Report problems to the maintainers by opening a private security advisory on GitHub or contacting a maintainer directly.
